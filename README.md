# Kit

A library you can copy. Free components, dot matrix empty state illustrations, effects, type and transitions for the web.

**[kit.orevbajohn.me](https://kit.orevbajohn.me)**

Every piece is a file with no dependencies and a prompt. Copy the code into your project, or paste the prompt into Claude Code, Codex or Cursor and let your agent build it in your own stack.

## What's inside

- **Components**: tactile UI pieces in light and dark, themed with the variables in `src/components/tokens.css`
- **Empty states**: 830 dot matrix illustrations that animate on hover or loop, downloadable as SVG or GIF
- **Libraries**: Ripple and Confetti pop
- **Type** and **Transitions**: canvas type effects and page transitions

## Run it locally

```sh
npm install
npm run dev
```

Built with Vite, React, TypeScript, Tailwind and Motion.
